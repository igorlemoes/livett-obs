Câmera para o OBS

Este endereço faz parte do plugin LiveTT (software livre, GPL-2.0-or-later). Ele só leva as mensagens que ligam o celular ao OBS; o vídeo e o som vão direto do celular para o computador e não passam por aqui.

Para usar o celular como câmera, adicione a fonte "Câmera do celular" no OBS e leia o QR code que aparece.
