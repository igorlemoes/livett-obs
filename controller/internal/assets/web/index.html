    Assistente de IA contexto e conexão

    O assistente usa isto para responder os espectadores durante esta LIVE. Informe mais detalhes sobre seus produtos (preço, tamanhos, prazo de entrega, etc.), sua gameplay, batalhas, etc. O texto fica salvo e vai com a próxima LIVE; durante uma LIVE, Atualizar na LIVE coloca a mudança no ar.

    Os interruptores só ligam durante a LIVE e valem só para ela. Sem eles, o assistente só envia mensagens que você aprovar.

    Conectar um assistente

    Cada botão copia a configuração pronta para esta instalação. Cole no terminal (Claude Code, Codex) ou nas configurações de MCP (Cursor e outros) e, por último, cole o guia no chat do assistente.

    Câmera do celular sem fio, pelo navegador

    Use o celular como câmera do OBS sem instalar nada nele: ele abre uma página, envia imagem e som pelo Wi-Fi e o OBS recebe numa fonte de navegador. O celular e este computador precisam estar na mesma rede.
