AVISOS DE SOFTWARE DE TERCEIROS — LiveTT
=======================================================

Este projeto é software livre (GNU GPL v2 ou posterior, arquivo LICENSE). O pacote de instalação contém, além do código do
projeto, apenas o que está listado abaixo. Nada do TikTok LIVE Studio, do TikTok ou da ByteDance é incluído.

1) Linguagem Go (biblioteca padrão e runtime) — dentro do controller.exe
   Licença BSD de 3 cláusulas. É obrigatório reproduzir o aviso abaixo em distribuições binárias.
   O controlador não usa nenhum módulo de terceiros além da biblioteca padrão do Go (controller/go.mod não tem "require").

2) OBS Studio (https://obsproject.com) — GNU GPL v2 ou posterior
   O plugin (livett.dll) é carregado pelo OBS e usa as interfaces dele (libobs, obs-frontend-api e o plugin
   obs-browser). O OBS não é distribuído neste pacote.

3) Qt 6 (https://www.qt.io) — GNU LGPL v3
   O plugin é ligado dinamicamente às bibliotecas Qt que o próprio OBS instala. Nenhuma biblioteca Qt é distribuída aqui.

4) Google Chrome — programa do próprio usuário
   O controlador usa o Chrome instalado no computador (perfil separado, só em %LOCALAPPDATA%\TikTokLiveOBS). Nada do Chrome é distribuído.

5) cloudflared (https://github.com/cloudflare/cloudflared) — Apache License 2.0 — OPCIONAL
   Se o usuário o instalar por conta própria, o controlador pode usá-lo para abrir um túnel HTTPS para a câmera do celular. Não é distribuído aqui.

6) Cloudflare Workers (https://workers.cloudflare.com) — serviço de terceiros
   O relay da câmera do celular (pasta worker/ do código-fonte) roda na plataforma da Cloudflare, sujeito aos termos dela.
   Só mensagens de conexão passam por lá; o vídeo e o som não.

7) Ferramentas de desenvolvimento do relay (apenas no repositório; não vão no pacote): wrangler/workerd/esbuild (Apache-2.0/MIT).
